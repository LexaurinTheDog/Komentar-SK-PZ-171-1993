# Komentár k zákonu č. 171/1993 Z. z., o Policajnom zbore

Odborný komentár k slovenskému zákonu o Policajnom zbore — základnému predpisu upravujúcemu postavenie, organizáciu a úlohy Policajného zboru, oprávnenia policajta (napr. požadovanie vysvetlenia, preukázanie totožnosti, zaistenie, použitie donucovacích prostriedkov a zbrane), povinnosti policajta, operatívno-pátraciu činnosť a informačno-technické prostriedky, spracúvanie osobných údajov vrátane medzinárodnej výmeny informácií a záznamov o cestujúcich (PNR), ako aj zodpovednosť štátu za škodu spôsobenú Policajným zborom. Zákon nadobudol účinnosť 15. júla 1993. Komentár pokrýva celý zákon (§ 1 – § 84) — **135 paragrafových jednotiek**; zákon neobsahuje novelizačné články meniace iné zákony.

Konsolidované znenie k **1. 7. 2026**, zdroj [slov-lex.sk](https://www.slov-lex.sk/static/SK/ZZ/1993/171/20260701.html).
